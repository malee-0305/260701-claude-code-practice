Selenium은 Chrome 브라우저를 제어하므로 ChromeDriver가 필요합니다.

1. 현재 설치된 Chrome 버전 확인 (`chrome://settings/help`)

3. `chromedriver.exe`를 프로젝트 폴더(또는 PATH)에 위치

```python
# app.py 상단에서 경로 지정
```

### 2-3. headless vs non-headless

```
headless=True  : 브라우저 창 없이 백그라운드 실행 (빠름)
               → 사용처: 콜금리, 환율, 기준금리
headless=False : 실제 브라우저 창 표시 (로그인·팝업 처리 가능)
               → 사용처: 채권정보센터, KRX (수동 로그인 필요)
```

## 4. Flask 앱 뼈대 만들기

### 4-1. 섹션 상태 관리

각 데이터 섹션은 독립적으로 실행·중지할 수 있어야 합니다.  
`threading.Event`를 사용해 중지 신호를 전달합니다.

```python
import time, threading
from datetime import datetime, timedelta
from flask import Flask, render_template, request, jsonify

app = Flask(__name__)

SECTIONS = ["investing", "fx", "bond", "call", "krx", "rates"]

def _fresh_state():
    return {
        "done":    False,
        "data":    None,
        "error":   None,
        "stop":    threading.Event(),   # 중지 요청 신호
        "running": False,
    }

_state = {s: _fresh_state() for s in SECTIONS}
```

### 4-2. 중지 체크 헬퍼

긴 루프 내에서 자주 호출해 중지 신호를 확인합니다.

```python
def stopped(sec): return _state[sec]["stop"].is_set()

def chk(sec):
    if stopped(sec):
        raise RuntimeError("조회가 중지되었습니다.")
```

### 4-3. Chrome 드라이버 팩토리

```python
def make_driver(headless=True):
    from selenium import webdriver
    from selenium.webdriver.chrome.service import Service

    opts = webdriver.ChromeOptions()
    if CHROME_BINARY:
        opts.binary_location = CHROME_BINARY
    if headless:
        opts.add_argument("--headless=new")

    for a in ["--no-sandbox", "--disable-dev-shm-usage", "--disable-gpu",
              "--window-size=1920,1080",
              "--disable-blink-features=AutomationControlled",
              "--ignore-certificate-errors"]:
        opts.add_argument(a)

    # 자동화 감지 우회
    opts.add_experimental_option("excludeSwitches", ["enable-automation"])
    opts.add_experimental_option("useAutomationExtension", False)

    driver = webdriver.Chrome(service=Service(CHROME_DRIVER), options=opts)
    driver.execute_script(
        "Object.defineProperty(navigator,'webdriver',{get:()=>undefined})")
    return driver
```

> **핵심 포인트**: `--disable-blink-features=AutomationControlled`와  
> `navigator.webdriver` 재정의를 함께 써야 대부분의 봇 차단을 우회할 수 있습니다.

### 4-4. 기본 라우트

```python
@app.route("/")
def index():
    return render_template("index.html")

@app.route("/api/result/<section>", methods=["GET"])
def api_result(section):
    s = _state[section]
    return jsonify({
        "done":    s["done"],
        "running": s["running"],
        "data":    s["data"],
        "error":   s["error"],
    })

@app.route("/api/stop/<section>", methods=["POST"])
def api_stop(section):
    if section == "all":
        for s in SECTIONS:
            _state[s]["stop"].set()
        return jsonify({"status": "stopped all"})
    _state[section]["stop"].set()
    return jsonify({"status": "stopped"})
```

### 5-1. Investing.com 글로벌 지수·금리·원자재

**방식**: `requests` + `BeautifulSoup` (Selenium 불필요)

```python
def run_investing(end_date: str):
    import requests, urllib3, pandas as pd
    from bs4 import BeautifulSoup
    urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

    # 날짜 포맷 변환: 20240101 → 2024년 01월 01일
    date_fmt = f"{end_date[:4]}년 {end_date[4:6]}월 {end_date[6:8]}일"

    sess = requests.Session()
    sess.headers.update({
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)...",
        "Accept-Language": "ko-KR,ko;q=0.9",
        "Referer": "https://kr.investing.com/"
    })

    def get_row(url, label):
        chk("investing")
        r = sess.get(url, verify=False, timeout=20)
        soup = BeautifulSoup(r.text, "html.parser")
        # 테이블에서 날짜가 일치하는 행 찾기
        table = soup.find("table", class_="freeze-column-w-1 ...")
        for row in table.find("tbody").find_all("tr"):
            cols = [c.get_text(strip=True) for c in row.find_all("td")]
            if cols and cols[0] == date_fmt:
                return [label] + cols
        return None
```

```python
def run_fx(date: str):
    date_fmt = f"{date[:4]}.{date[4:6]}.{date[6:8]}"  # 2024.01.01

    fx_codes = {
        "달러(USD)": "FX_USDKRW",
        "위안(CNY)": "FX_CNYKRW",
        "엔(JPY)":   "FX_JPYKRW",
    }

    def fetch_naver_fx(market_code, max_pages=10):
        base_url = ("https://finance.naver.com/marketindex/exchangeDailyQuote.nhn"
                    f"?marketindexCd={market_code}")
        for page in range(1, max_pages + 1):
            chk("fx")
            r = sess.get(base_url + f"&page={page}", timeout=15)
            soup = BeautifulSoup(r.text, "html.parser")
            for row in soup.select("table.tbl_exchange tbody tr"):
                cols = [td.get_text(strip=True) for td in row.find_all("td")]
                if cols and cols[0] == date_fmt:
                    return float(cols[1].replace(",", ""))
        return None
```

**iframe 구조**:

```
window
└── fraAMAKMain (frame)
    └── maincontent (frame)
        └── tabContents1_contents_tabs1_body (frame)  ← 실제 데이터
```

```python
def run_bond(date: str):
    driver = make_driver(headless=False)   # 팝업 처리를 위해 non-headless

    def switch_to_main_frame():
        driver.switch_to.default_content()
        driver.switch_to.frame(driver.find_element(By.NAME, "fraAMAKMain"))

    def switch_to_nested():
        switch_to_main_frame()
        driver.switch_to.frame(driver.find_element(By.ID, "maincontent"))
        driver.switch_to.frame(
            driver.find_element(By.ID, "tabContents1_contents_tabs1_body"))
        time.sleep(3)

    def dismiss_popup():
        try:
            WebDriverWait(driver, 8).until(
                EC.element_to_be_clickable((By.XPATH, '//*[@id="popup_ok"]'))).click()

    driver.get("https://www.kofiabond.or.kr/")
```

**KRX 로그인 대기 패턴**:

KRX는 첫 진입 시 사용자가 직접 로그인해야 하는 경우가 있습니다.  
`threading.Event`를 사용해 사용자가 "계속" 버튼을 누를 때까지 대기합니다.

```python
_krx_login_event = threading.Event()

# 브라우저 오픈 후 대기
_krx_login_event.wait()    # 사용자가 /api/krx-continue 호출할 때까지 블록
_krx_login_event.clear()

# 프론트엔드에서 "계속" 버튼 클릭 → POST /api/krx-continue
@app.route("/api/krx-continue", methods=["POST"])
def api_krx_continue():
    _krx_login_event.set()
    return jsonify({"status": "ok"})
```

**인도네시아·베트남 기준금리 (World Bank API)**:

```python
def fetch_wb_rate(country_code, country_name, indicator="FR.INR.DPST"):
    url = (f"https://api.worldbank.org/v2/country/{country_code}"
           f"/indicator/{indicator}?format=json&mrv=20&per_page=20")
    r = requests.get(url, timeout=15)
    data = r.json()
    # [meta, [records...]] 구조
    records = [d for d in data[1] if d.get("value") is not None]
    records.sort(key=lambda x: x.get("date", ""), reverse=True)

    latest = records[0]
    prev   = records[1] if len(records) > 1 else latest
    vals   = [d["value"] for d in records]
    years  = sorted(set(d["date"] for d in records))

    return {
        "국가":          country_name,
        "실제":          str(round(latest["value"], 2)),
        "이전":          str(round(prev["value"],   2)),
        "최고":          str(round(max(vals), 2)),
        "최저":          str(round(min(vals), 2)),
        "날짜":          f"{years[0]}-{years[-1]}",
        "단위":          "퍼센트",
        "업데이트 주기":  "매일",
    }
```

## 6. NXT 데이터 엑셀 업로드 처리

NXT(코스피·코스닥 대체거래소) 거래대금은 공식 API가 없으므로  
사용자가 엑셀 파일을 직접 업로드하는 방식으로 처리합니다.

### 6-1. 엑셀 파일 구조 (예시)

| A열 (시장) | B열 (투자자구분) | C열 (매도) | D열 (매수) |
|-----------|----------------|-----------|-----------|
| 코스피 | 개인 | 1000000 | 2000000 |
| 코스피 | 기관종합 | 5000000 | 3000000 |
| 코스닥 | 기타 | 200000 | 100000 |

### 6-2. 파싱 로직

```python
@app.route("/api/krx-nxt-upload", methods=["POST"])
def api_krx_nxt_upload():
    import openpyxl, io

    f = request.files.get("file")
    wb = openpyxl.load_workbook(io.BytesIO(f.read()), data_only=True)
    ws = wb.active

    kospi_map  = {}
    kosdaq_map = {}

    for row in ws.iter_rows(min_row=2, values_only=True):
        market = str(row[0]).strip()
        inv    = str(row[1]).strip()
        sell   = float(str(row[2]).replace(",", ""))
        buy    = float(str(row[3]).replace(",", ""))

        if "코스피" in market:
            kospi_map[inv]  = {"매도": sell, "매수": buy}
        elif "코스닥" in market:
            kosdaq_map[inv] = {"매도": sell, "매수": buy}

    _nxt_data["kospi"]  = kospi_map
    _nxt_data["kosdaq"] = kosdaq_map
```

## 7. 비동기 처리 구조

### 7-1. 섹션 스레드 래퍼

각 섹션은 별도 스레드에서 실행되어 UI가 블로킹되지 않습니다.

```python
def _run_section(sec, fn, *args):
    try:
        _state[sec]["running"] = True
        _state[sec]["done"]    = False
        _state[sec]["data"]    = None
        _state[sec]["error"]   = None
        _state[sec]["stop"].clear()

        if sec == "rates":
            df_main, df_te, err = fn()
            if err:
                _state[sec]["error"] = err
            else:
                html  = "<h4>Investing.com 중앙은행 금리</h4>"
                html += df_main.to_html(classes="data-table", ...)
                html += "<h4>인도네시아·베트남 기준금리</h4>"
                html += df_te.to_html(classes="data-table", ...)
                _state[sec]["data"] = html
        else:
            df, err = fn(*args)
            if err:
                _state[sec]["error"] = err
            else:
                _state[sec]["data"] = df.to_html(classes="data-table", ...)

    except RuntimeError as e:
        _state[sec]["error"] = str(e)
    except Exception as e:
        _state[sec]["error"] = str(e)
    finally:
        _state[sec]["done"]    = True
        _state[sec]["running"] = False
```

### 7-2. 실행 API

```python
@app.route("/api/run/<section>", methods=["POST"])
def api_run(section):
    body       = request.get_json() or {}
    end_date   = body.get("end_date", "").replace("-", "")
    start_date = body.get("start_date", "").replace("-", "")

    # 주말 자동 보정
    end_date = adjust_to_biz_day(end_date, direction="back")

    fn_map = {
        "investing": (run_investing, [end_date]),
        "fx":        (run_fx,        [end_date]),
        "bond":      (run_bond,      [end_date]),
        "call":      (run_call,      [end_date]),
        "rates":     (run_rates,     []),
    }
    fn, args = fn_map[section]
    t = threading.Thread(
        target=_run_section, args=(section, fn, *args), daemon=True)
    t.start()
    return jsonify({"status": "started"})
```

## 8. 단위 변환 핵심 로직

### 8-1. 시가총액: 백만원 → 조원

KRX MDI는 시가총액을 **백만원** 단위로 반환합니다.

```
원본 값 (백만원)  →  ÷ 1,000,000  →  조원
예: 1,000,000 백만원 = 1 조원
```

```python
def to_trillion(df, cols):
    """지정 컬럼을 백만원 → 조원으로 변환"""
    d = df.copy()
    for c in cols:
        if c in d.columns:
            d[c] = d[c].apply(
                lambda x: round(tf(x) / 1e6, 4)
                if str(x).strip() not in ("", "nan", "-") else "-"
            )
    return d

# 적용
```

## 9. NXT 투자자별 합산 로직

### 9-1. 기관(조원) 계산

**정의**: 코스피 기타 + 코스피 기관종합 + 코스닥 기타 + 코스닥 기관종합

```python
def nxt_get(mkt_dict, *keys):
    """정확한 키 우선 매칭 (부분 매칭보다 먼저)"""
    total = 0.0
    for k in keys:
        if k in mkt_dict:
            # 정확히 "기타"인 항목만 → "기타외국인" 제외
            total += mkt_dict[k]["매도"] + mkt_dict[k]["매수"]
        else:
            matched = next((dk for dk in mkt_dict if k in dk), None)
            if matched:
                total += mkt_dict[matched]["매도"] + mkt_dict[matched]["매수"]
    return total

# 기관 = 기타 + 기관종합
nxt_기관 = nxt_get(kospi_dict, "기타", "기관종합") + \
           nxt_get(kosdaq_dict, "기타", "기관종합")
```

> **주의**: 단순 부분 매칭(`"기타" in key`)으로 검색하면  
> "기타외국인", "기타금융" 등이 함께 잡혀 값이 틀려집니다.  
> **정확한 키 일치를 우선 확인**해야 합니다.

### 9-2. 전체(조원) 이중계산 방지

**문제**: "기관종합"은 금융투자 + 보험 + 투신 + 은행 + ... 의 합계입니다.  
전체 합산 시 기관종합을 포함하면 하위 항목과 이중계산됩니다.

```python
def nxt_total_val(key_label):
    val = 0.0
    for mkt in [_nxt_data["kospi"], _nxt_data["kosdaq"]]:
        if key_label == "전체":
            for k in mkt:
                if "기관종합" not in k:   # 기관종합 제외 → 이중계산 방지
                    val += mkt[k]["매도"] + mkt[k]["매수"]
        elif key_label == "기관":
            val += nxt_get(mkt, "기타", "기관종합")
    return round(val / 1e12, 2)
```

**계산 구조 시각화**:

```
전체 합계 = 개인 + 외국인 + 기타외국인 + 기타(법인)
           + 금융투자 + 보험 + 투신 + 사모 + 은행 + 기타금융 + 연기금
           (기관종합 제외 — 위 항목들의 합이므로)
```

### 오류 3: 데이터 없음 (날짜 문제)

```
RuntimeError: 데이터 없음 (최대 10일 소급)
```

**해결**: 공휴일이나 주말에는 데이터가 없으므로, 자동 소급 로직이 필요합니다.

```python
def adjust_to_biz_day(date_str, direction="back"):
    d = datetime.strptime(date_str, "%Y%m%d")
    step = timedelta(days=-1) if direction == "back" else timedelta(days=1)
    while d.weekday() >= 5:   # 5=토, 6=일
        d += step
    return d.strftime("%Y%m%d")
```

### 오류 4: TradingEconomics 410 오류

```
HTTP 410: We are sorry, but the guest account has been discontinued.
```

**해결**: TradingEconomics API는 더 이상 무료로 사용할 수 없습니다.  
World Bank API(`https://api.worldbank.org/v2/`)로 대체합니다.

### 오류 5: NXT 기관 합산 오류 (부분 매칭 문제)

**증상**: "기타"를 검색했는데 "기타외국인"이 먼저 매칭됨

**해결**: 정확한 키 일치를 먼저 확인합니다.

```python
# 잘못된 방법 (부분 매칭만)
matched = next((dk for dk in mkt_dict if "기타" in dk), None)
# → "기타외국인" 등이 먼저 매칭될 수 있음

# 올바른 방법 (정확한 키 우선)
if "기타" in mkt_dict:
    total += mkt_dict["기타"]["매도"] + mkt_dict["기타"]["매수"]
else:

```
